面向高风险公共部门的两类场景（就业与工人管理 Annex III(4)；基本公共服务获取 Annex III(5)(a)），构建150条记录的策展语料库，用关键词、LLM和混合方法沿四个轴进行标注，并序列化为包含1,351个RDF三元组、可用SPARQL查询的知识图谱；通过五个FRIA演示场景进行覆盖测试，并与69条记录的黄金标准进行对比评估。
为什么值得看
与检索增强及知识图谱主题直接相关：它展示如何用知识图谱组织检索证据以支持下游对齐与合规评估任务，并报告了LLM辅助分类在公平性相关证据检索中的表现。
阅读提示
摘要仅覆盖两个高风险公共部门类别且在150条记录的小规模语料上标注；LLM辅助的就业领域分类与黄金标准一致性极低（κ=0.045），说明自动化公平性相关证据检索在该领域不可靠，结论不宜外推到其他领域或更大规模场景。
