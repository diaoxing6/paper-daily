计算生物学GRN / Regulon
中文速读AI 中文解读

利用时间分辨单细胞多组学在斑马鱼中鉴定出肌隔内 prrx1+ 肌腱相关祖细胞群，并揭示一条进化上保守的 prrx1-wwp2 增强子轴调控其成骨分化，连接斑马鱼生理性肌腱骨化与哺乳动物病理性异位骨化。

方法
对斑马鱼肌腱骨化过程进行时间分辨 scRNA-seq 与 scATAC-seq，重建相关基因调控网络；进行斑马鱼与哺乳动物的跨物种整合；通过功能扰动验证 prrx1 的作用；将 GWAS 与跨物种 scRNA-seq 整合以识别 wwp2；用顺式调控分析鉴定保守的 wwp2 增强子。
为什么值得看
与 GRN/Regulon 主题相关：工作基于单细胞转录组与染色质可及性数据重建基因调控网络，并结合增强子顺式调控分析确定 prrx1 对 wwp2 的调控关系。
阅读提示
摘要未说明样本规模、扰动实验的具体类型与统计效力；跨物种保守性主要基于细胞与分子特征整合及有限的功能验证，机制结论在哺乳动物体内的普适性仍待进一步验证。
